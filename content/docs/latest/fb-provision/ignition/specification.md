Ignition should not be written by hand but using [Butane][butane]; that said the specification is available here: https://coreos.github.io/ignition/specs/

_Note_: Flatcar still supports old Ignition specifications (v1 and v2) but users are actively encouraged to migrate to v3 - if Butane is used to generate Ignition then you are good.
